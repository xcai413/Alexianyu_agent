# 验证记录

> 本仓库只保留不含运行环境、账号、凭据、业务数据或机器标识的验证结论。详细真实运行证据存放在受访问控制的位置，不提交到 Git。

## 离线测试

- 消息、会话、规则、订单、库存、账号池、守护进程和数据库迁移均有单元或集成测试覆盖。
- 最新权威结果以 CI 与本地 `uv run pytest -q` 为准。
- 静态检查使用 `uv run ruff check .`；阻断范围内的类型检查使用 CI 配置的 mypy 命令。

## 真实环境验证边界

- 扫码登录、商品只读同步、订单只读同步、守护进程控制和 Windows 恢复能力曾在受保护环境中验证。
- 真实消息收发、断网恢复、Windows 重启恢复与长稳验收必须按当前计划重新执行并独立留存证据。
- 自动回复和自动发货默认关闭；真实外发动作必须取得明确授权。

## 证据处理规则

- 不提交二维码、Cookie、Token、Fernet 密钥、设备标识、日志、SQLite 数据库、订单、买家资料、卡密或进程标识。
- 协议捕获仅允许保存字段结构、类型、长度和不可逆摘要。
- 发现疑似泄露时，立即轮换凭据并从全部 Git 历史与远端副本中清除相关对象。
