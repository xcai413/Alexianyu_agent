## 多副本地基(M1)验证(2026-09-20)

抢占租约与实例租约的验收结果(SQLite 单测 + Postgres 16 / MySQL 8.4 真库契约):

- outbox 抢占:同一事件被 `owner-a` 抢到后,`owner-b` 在租约有效期内拿不到;租约到期后可接管,
  且换发新 token。SQLite 单测与三库契约用例都覆盖了这条。
- 失败即释放租约:发布失败会立刻归还租约,重试不用等 TTL;发布成功但标记提交失败时,
  重投推迟到租约到期——at-least-once 语义保留,只是不再立刻重投。
- 实例租约:`create_instance` 落租约、`touch_heartbeat` 续租;`mark_expired_instances` 只清理
  租约过期(或升级前无租约且心跳也已过期)的行,仍在心跳的旧版本进程不会被误标。
- 命令定向:`fail_stale_running` 只把 owner 缺失或租约过期的 running 命令置失败,活跃实例的
  命令保持 running——这正是多副本下「A 在执行、B 判它失败并重做」的防线。
- 迁移 `a4d17f2c8e35` 在 SQLite / Postgres 16 / MySQL 8.4 上均升级成功;Postgres 上 CI 同款
  受控契约 9/9 通过,MySQL 上 8/9 通过(见下)。
