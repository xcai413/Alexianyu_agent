## 关注点与排查

| 异常 | 排查 |
|------|------|
| `reconnects` 涨 | WS 抖动/服务端重连;看 `last_error` 全文 |
| `last_error` 非 `-` | 粘完整错误 |
| `card consume` 报"无可用卡密" | 正常;先 `card restock` |
| `protocol inject` 走不动 | 看 `pool status` 中 `last_error` |
| TUI 看不到消息 | `message list --account xcaicai --since 1h` 有数据吗?真实推送需买家发消息 |
| `pool start` 提前退出 | 到 `--seconds` 期限 → 正常;否则查 `last_error` |
