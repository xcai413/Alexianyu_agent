# 真实功能测试清单

> 此清单只记录可复现的验证步骤。账号标识、二维码、Cookie、Token、订单、买家、卡密、运行日志和机器信息只能保留在本地受保护的运行记录中，不得提交。

## 准备

- [ ] `uv run xianyu-agent --version` 能正常输出版本。
- [ ] 在本地受保护环境中完成账号登录；不要把凭据、二维码或终端输出写入仓库。
- [ ] `uv run xianyu-agent doctor` 的数据库、迁移、密钥和日志目录检查通过。

## 离线验证

- [ ] 执行 `uv run pytest -q` 与 `uv run ruff check .`。
- [ ] 用 `demo` 账号执行规则 dry-run，确认关键词命中和未命中结果。
- [ ] 用仓库内的脱敏 fixture 执行 `protocol inject`，确认消息与订单状态能持久化。
- [ ] 验证卡密扣减、频率限制、静默时段和金额限制在本地测试库中生效。

## 真实账号观察模式

- [ ] 以 `observe` 模式启动 daemon，并记录脱敏后的健康状态。
- [ ] 校准一条真实入站消息；原始帧仅能保存为不可逆脱敏结构。
- [ ] 复核重复推送不会产生重复消息或重复未读数。
- [ ] 执行只读商品或订单同步；不得提交任何同步结果。

## 自动化与恢复

- [ ] 仅在明确授权后启用单个商品的自动回复或发货。
- [ ] 验证 daemon 停止、进程异常、断网恢复和 Windows 重启恢复。
- [ ] 长稳验收期间检查日志，确认未出现 Cookie、Token、Fernet 密钥、订单、买家或卡密明文。

## 记录规范

记录结论时只写测试版本、日期、命令、通过/失败和脱敏统计。真实运行证据留在未追踪的 `data/` 目录或受访问控制的外部存储。
