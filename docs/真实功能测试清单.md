## 三、订单与自动发货(注入 Fake 订单帧,触发 DeliveryService)

先准备 fixture + 卡片:

```powershell
# 5a. 准备 fixture(实际路径:tests/fixtures/,已随仓库提交)
@"""
{"code": 0, "body": {"bizType": "order", "5": {"orderId": "TEST-001", "buyerId": "b", "amount": 5.0, "status": "paid"}, "100": {"itemId": "I-1", "title": "测试商品"}}}
{"code": 0, "body": {"bizType": "order", "5": {"orderId": "TEST-001", "status": "delivered"}}}
""" | Set-Content -Encoding utf8 tests/fixtures/order_paid.jsonl
@"""
{"code": 0, "body": {"bizType": "order", "5": {"orderId": "HIGH-001", "buyerId": "b", "amount": 99999.0, "status": "paid"}, "100": {"itemId": "I-1", "title": "天价商品"}}}
""" | Set-Content -Encoding utf8 tests/fixtures/order_high.jsonl

# 5b. 确保有卡密
uv run xianyu-agent card add --account xcaicai --name 测试卡 --content "TEST-CODE-1"

# 5c. 注入普通订单
uv run xianyu-agent protocol inject --account xcaicai --fixture tests/fixtures/order_paid.jsonl --count 1
uv run xianyu-agent order list --account xcaicai
uv run xianyu-agent card list --account xcaicai
# 期望:order TEST-001 status=paid(离线注入无 socket,发送必然失败),
#       delivery_fail_reason=发送器返回失败,卡密被预留(remaining 减 1),
#       用 `order redeliver <id>` 在线重试后 status=delivered

# 5d. 注入高额订单(> 默认 max_order_amount=9999)
uv run xianyu-agent protocol inject --account xcaicai --fixture tests/fixtures/order_high.jsonl --count 1
uv run xianyu-agent order list --account xcaicai | Select-String "HIGH"
# 期望:order HIGH-001 status=paid, delivery_fail_reason=guardrail: 订单金额超限(...)
#       audit_logs 有 guardrail_block;卡密未被扣减
uv run xianyu-agent maintenance purge-messages --older-than 0
uv run xianyu-agent auth status --account xcaicai
```

> 2026-08-10 实测:✅ 全部符合。另发现两处真实缺陷并已修复:
> 1. 发货失败后卡密被预留但无重试命令 → 新增 `order redeliver <id>`(复用预留卡密,失败可重试;guardrail 拦截的订单重试仍会被拦截,不会误发)。
> 2. guardrail 拦截原因未写入订单行 → 已修复,`order show` 现在显示 `失败原因: guardrail: 订单金额超限(...)`。
> 3. `order show` 原来显示 account=数字 id → 已修复为账号名。

## 关注点与排查

| 异常 | 排查 |
|------|------|
| `reconnects` 涨 | WS 抖动/服务端重连;看 `last_error` 全文 |
| `last_error` 非 `-` | 粘完整错误 |
| `card consume` 报"无可用卡密" | 正常;先 `card restock` |
| `protocol inject` 走不动 | 看 `pool status` 中 `last_error` |
| TUI 看不到消息 | `message list --account xcaicai --since 1h` 有数据吗?真实推送需买家发消息 |
| `pool start` 返回退出码 2 | daemon 不在线/心跳过期/等待超时;看 `daemon status` 与命令记录 |
