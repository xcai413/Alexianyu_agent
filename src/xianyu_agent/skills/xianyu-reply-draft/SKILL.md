# 闲鱼回复草稿

## 何时使用

- 需要人工回复时(售后、砍价、复杂问题、或用户要求"帮我回一下")。
- 已有规则但回复不够贴切,需要按上下文重写。

## 起草要求

1. **先取上下文**:`xianyu-agent message list --account <id> --since 30m` + `xianyu-agent order list --account <id>`。
2. **语气**:像真实卖家,简短、礼貌、口语化;避免 AI 味(不用"亲爱的用户"、"感谢您的咨询")。
3. **结构**:先回应买家问题,再给关键信息(价格/发货时间/售后路径),最后一句推进。
4. **禁忌**:
   - 不承诺平台规则外的事(如"绝对不封号")
   - 不暴露自动化系统存在
   - 售后场景不推卸责任

## 模板参考

- **询价**:在的,9.9 包邮,今天拍今天发。
- **砍价**:最低 9.5 啦,再低真不行了,送个小礼品。
- **催发**:刚打包好,马上叫快递,预计明天到。
- **售后**:先别急,我这边核对一下订单,马上处理。

## 输出格式

草稿 + 2 行说明(依据的上下文 + 建议发送时机),如:

> 草稿:在的,9.9 包邮,今天拍今天发。
> 依据:买家 2 分钟前问"还在吗",商品标题含 9.9。
> 发送:确认后 `xianyu-agent message send`(Phase 7 起)。
