# 闲鱼消息分诊

## 何时使用

- Worker 收到新买家消息,需要判断意图后决定:直接规则回复、人工确认、还是走发货/售后流程。
- 消息内容含"多少钱 / 便宜 / 发了吗 / 怎么还没发货 / 退 / 举报"等关键词时。

## 前置

- 先执行 `xianyu-agent message list --account <id> --since 10m` 拿到会话上下文。
- 用 `xianyu-agent message show <id>` 看单条消息原文与原始 payload。

## 分诊流程

1. **读消息**:确认方向为 `inbound`(买家 → 我),忽略 `outbound` 与系统通知。
2. **意图分类**(按优先级):
   - `售后` — 含"退/换/坏了/不能用/没收到" → 转人工,绝不自动发货
   - `催发` — 含"还没发货/什么时候发" → 查订单状态,再回复
   - `砍价` — 含"便宜/少点/再优惠" → 规则/话术回复,不自动改价
   - `询价` — 含"多少钱/在吗/有货吗" → 正常商品介绍回复
   - `广告/骚扰` — 含链接+无关内容 → 忽略,不回复
3. **决定动作**:
   - 命中 `xianyu-agent rule test --content "<消息>" --account <id>` 已有规则 → 让规则引擎处理
   - 未命中且属于售后/砍价 → 起草回复给用户确认
   - 无法判断 → 标记 `processed=0`,不自动回复

## 输出

一句话结论 + 建议动作,例如:

> 买家在催发货(intent=催发),订单 D-1 状态 paid 未发货 → 建议立即查卡密库存并走发货流程。
